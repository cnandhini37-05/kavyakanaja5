# KavyaKanaja5 📱✨

## 📌 Project Overview

KavyaKanaja5 is an Android application developed using **Kotlin** and **Jetpack Compose**.
The app is designed to display a collection of poems in a clean and user-friendly interface, making it easy for users to read and enjoy poetry.

---

## 🎯 Features

* 📖 Browse and read poems
* 🎨 Clean and modern UI using Jetpack Compose
* 📜 Scrollable poem list
* 💡 Simple and easy-to-use design
* ⚡ Lightweight and fast performance

---

## 🛠️ Technologies Used

* **Kotlin**
* **Android Studio**
* **Jetpack Compose**
* **Material UI**

---

## 📱 App Screens

* Home screen displaying list of poems
* Poem detail view (full content)

---

## 🚀 How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/cnandhini37-05/kavyakanaja5.git
   ```
2. Open the project in **Android Studio**
3. Let Gradle sync complete
4. Click **Run ▶️** to launch the app

---

## 📂 Project Structure

* `app/src/main/java/...` → App source code
* `ui/` → UI components (Compose)
* `data/` → Poem data/repository
